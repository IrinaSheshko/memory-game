# Memory-game

Веб-игра на запоминание карточек, написанная на чистом JavaScript, HTML5 и CSS3.

## 🚀 Описание проекта

Цель игры — найти все 8 пар одинаковых карточек за минимальное количество ходов. 

## ✨ Функционал

- **Игровое поле 4x4**: 16 карточек с случайным перемешиванием при каждой новой игре.
- **Счётчики**: Отслеживание количества сделанных ходов и угаданных пар в реальном времени.
- **Таблица лидеров (Leaderboard)**:
  - Автоматическое сохранение 10 лучших результатов в `localStorage`.
  - Сортировка по минимальному числу ходов и дате прохождения (`ДД.ММ.ГГГГ`).
- **Доступные модальные окна**:
  - Использование семантического тега `<dialog>`.
  - Закрытие тремя способами: кнопка «Закрыть», клик по затемнённому фону (backdrop) или клавиша `Escape`.
  - Блокировка прокрутки страницы при открытом окне.

## 🛠 Технологии

- **HTML5** 
- **CSS3** (CSS Grid, Flexbox, Media Queries для адаптивности)
- **JavaScript (ES6+)** (DOM API, `localStorage`, обработка событий)
